# 大 π 键成键可视化

**AI赋能高中化学教学系列 by 实验中学**

面向高中化学课堂与竞赛拓展的交互式教学网页。通过可旋转的 3D 模型、成键进度、轨道相位对比和互动练习，帮助学生理解平行 p 轨道的侧面重叠、离域 π 体系及其常见误区。

## 快速开始

1. 下载仓库中的 `index.html`，用现代桌面浏览器打开；也可以在本地用静态文件服务器预览。
2. 首次打开需联网：页面通过 CDN 加载 Vue 3、Three.js 和 Tailwind CSS。无需安装 npm 依赖或构建项目。
3. 从左侧模块导航进入专题；在手机或窄屏上，可横向滑动模块导航。

> 页面代码集中在 `index.html`，没有外部图片文件。使用 `file://` 打开时也仍需联网获取上述脚本。

## 教学内容

| 模块 | 主题 |
| --- | --- |
| 0–1 | 大 π 键的判据；从独立 p 轨道到侧面重叠和离域云 |
| 2–3 | 苯的 Π₆⁶；相位与轨道节点的对照 |
| 4–6 | 丁二烯、平面型无机离子、O₃ 与 SO₂ 的三中心四电子示意 |
| 7 | 吡啶、吡咯、呋喃、环戊二烯负离子、萘、石墨层等竞赛拓展 |
| 8 | 常见误区与苯的“固定局域键”错误假设对比 |
| 9 | 互动自测、即时反馈与解析 |

**建议的课堂路径：**先用模块 0 的判据工具判断参与原子和 π 电子数，再到模块 2 观察苯的三态模型、播放或分步讲解；接着在模块 3 比较相位，在模块 8 辨析错误模型，最后进入模块 9 自测。

主操作区提供播放、重置、成键进度以及适用模块的“三态”切换；“详细设置”中可调整速度、原子间距、视角、物种和显示开关。画布支持拖动旋转与缩放；触屏可单指旋转、双指缩放。未聚焦控件时，可用空格播放/暂停、`R` 重置、左右方向键微调进度。地址栏可使用 `#benzene` 等模块锚点直达课堂内容。

## 科学边界

- 粒子云是**简化 LCAO 的单个轨道组合及其相位示意**，不是全部占据轨道叠加得到的真实总电子密度；不能用图中亮度或红蓝颜色推断电荷密度、能量或电荷正负。
- 成键进度用于教学演示，并不代表真实化学键形成的时间演化。相位对比中的交替系数用于展示某个示意轨道的节点，不代表苯的整个 π 电子体系。
- 苯的凯库勒式可以作为共振表示；模块 8 的“三对固定 π 键”是**待辨析的错误假设**。其中人为分开的云团只是教学对比，不是计算得到的另一种真实苯。
- 键长、键角采用教学常用值，标注“约”的数值应按近似值理解。判据工具按参与原子的 p 电子贡献计数，负电荷的贡献已包含在相关原子中，不应在求和后再加一次。
